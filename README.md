# Moonhour website

Static pages for the Moonhour iOS app, served by GitHub Pages:

- `/` home
- `/privacy/` privacy policy (linked from the app and App Store Connect)
- `/support/` support page (the App Store Connect Support URL)

Plain HTML and CSS, no build step. Edit the page and push; GitHub Pages updates within a minute or two.
The app's source code lives in a separate, private repository.
